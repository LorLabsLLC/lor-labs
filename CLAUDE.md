# lor-labs

## Overview

Single-file static landing page for Lor Labs LLC (`index.html`, no build step). Retro palette is defined as tokens on `:root`.

## Commands

- Build: none (static)
- Preview: `open index.html`
- Regenerate link-preview image (`og/card.html` → `og-image.png`): `"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --hide-scrollbars --virtual-time-budget=5000 --window-size=1200,630 --screenshot=og-image.png "file://$PWD/og/card.html"`
